# B-001 — CozyCorner: хлебные крошки на странице категории зажаты над баннером

**Что.** На `/shop/<категория>` (например `/shop/bags`) хлебные крошки «Home / Shop / Bags» стоят узкой полоской (~45px) на сером фоне между липкой шапкой сайта и полноширинным фото-баннером.
Выглядят как «случайная строка»: нет воздуха сверху и снизу, цвет текста слабый, на баннер крошки не опираются визуально.

**Где.** `cozycorner/app/shop/[category]/page.tsx` — `<Breadcrumbs items={breadcrumbItems} />` рендерится перед `<Hero hero={hero} />`; стили — `components/Breadcrumbs.module.css`.
(На `/product/[slug]` те же крошки без баннера выглядят нормально.) Проверено на боевом сайте 2026-10-16 скриншотом (1440px).

**Варианты (предложил владелец 2026-10-16).** (1) над блоком фильтров (под баннером); (2) над сеткой товаров; (3) внутрь белой плашки баннера (над словом CATEGORY).
Решение для Urban Gardener (шапка без баннера): крошки внутри шапки страницы над eyebrow и заголовком — единообразно со страницей статьи.

**Рекомендация для CozyCorner.** Вариант 3 — внутрь белой плашки, над «CATEGORY» (мелким текстом, с нормальными отступами): крошки остаются в шапке страницы, баннер не разрывается,
структура та же, что выбрана для Urban. Альтернатива — вариант 1 (полоска под баннером над фильтрами).

**Нужно решение владельца:** вариант (1/2/3) для CozyCorner. Правка небольшая (компонент `Hero` получает слот/пропс для крошек, страницы категории передают их), + тест; **URL-ы CozyCorner не менять** (см. B-003).

**Статус:** ждёт решения.
