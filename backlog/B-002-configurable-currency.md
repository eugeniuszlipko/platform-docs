# B-002 — Настраиваемая валюта (идея фичи)

**Что.** Владелец (2026-10-16): валюта не должна быть зашита в код. Возможно, выбор валюты **на сайт** и/или **на товар** в админке. Решение предварительное: «возможно, будем заниматься созданием этой фичи».

**Что уже заложено в Фазе 3 (urban.gardener).** У товара числовая цена `price` и код валюты `currency` (ISO 4217, по умолчанию `EUR`). Валюту можно менять данными в админке без миграции.
Форматирование цены — одна функция по коду валюты (`Intl.NumberFormat`).

**Что НЕ решено (и входит в эту фичу).**
- Валюта сайта по умолчанию (настройка сайта; у нового товара подставляется она).
- Фильтр по цене при смешанных валютах: пока диапазоны считаются в «единицах» одной валюты каталога; при разных валютах фильтр Price скрывается. Настоящее решение — конвертация или фильтр «по валюте».
- Домен Amazon/партнёрская сеть под валюту/рынок (US `amazon.com`, EU `amazon.de`…) — сейчас ссылка целиком вводится в админке, ничего не привязано.
- Структурированные данные цены (`Product` JSON-LD, Фаза 8) требуют кода валюты — поле уже есть.

**Нужно решение владельца:** делать ли фичу, на каком уровне (сайт / товар / оба), когда (после Фазы 3 или после запуска).

**Статус:** новая. Связано: B-001 нет; Фаза 3 (data model), Фаза 8 (JSON-LD).
