# B-009 — Favicon и картинка для соцсетей (og:image) меняются из админки

**Что.** Владелец (2026-10-19, при утверждении плана «Фокус и клавиатура»): favicon/иконку и картинку по умолчанию для соцсетей (`og:image`) нужно менять **из админки**, а не файлами в репо. Первую версию обеих рисует агент (простой текст-логотип + слоган на фирменных цветах), потом владелец заменяет сам.

**Где проявляется.** Urban Gardener: сейчас `/favicon.ico` → 404, `public/og-default.jpg` не существует (`buildPageMetadata`, `Organization.logo`). Админка: Pages → Site settings.

**Предложение.** В Site settings два поля загрузки (favicon/иконка; og:image 1200×630) с подсказкой по размерам, хранение в Supabase Storage, сайт читает URL из `site_settings` (метаданные `icons` и `openGraph.images` через `generateMetadata`, с запасной картинкой по умолчанию). Нужна миграция (колонки в `site_settings` + права, как в B-004/«column-level grants») и изменения в двух репо (urban.gardener + web.admin) → уровень 3 (дизайн-спека, ревью БД). Вопросы владельцу при планировании: форматы и ограничения размера, нужна ли отдельная иконка для iPhone (apple-icon 180) или одна картинка, нужно ли отдельное og-изображение на статью/товар (сейчас берётся из обложки).

**Нужно решение владельца.** В какую фазу: логично в Фазу 9 (запуск) как отдельный шаг до включения индексации — подтвердить при «Планируем фазу 9».

**Статус:** в плане — Фаза 9 (запуск), шаг 9.0a. Записана 2026-10-19.
