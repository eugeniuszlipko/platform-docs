# B-005 — Шапка Urban Gardener не помещается в 320px (кнопка меню выступает на 4px)

**Что.** При a11y-ревью Фазы 5 (2026-10-16) замечено и подтверждено в браузере: на ширине 320px правый край кнопки «Menu» = 324px (`overflow-x: clip` на `html/body` скрывает переполнение, но кнопка частично за краем). Бренд «Urban Soul of Plants» (`white-space: nowrap`) + кнопки поиска и меню суммарно шире 320px.

**Где проявляется.** `urban.gardener/components/Header.module.css` (`.brand b`, мобильный `.topbar`), все страницы, ширина ≤ ~330px (iPhone SE 1-го поколения, 400% zoom десктопа). Код Фазы 1, не Фазы 5.

**Предложение.** На ≤ 640px разрешить бренду сжиматься/переноситься (`.brand { min-width: 0 }`, `b { white-space: normal; line-height: 1.1 }`) или скрыть слоган до ≤ 360px; добавить e2e на 320px: `scrollWidth ≤ innerWidth` и кнопка меню целиком во вьюпорте. Решение по внешнему виду (перенос слогана vs скрытие) — за владельцем.

**Нужно решение владельца.** Как должен выглядеть бренд в шапке на очень узких экранах.

**Статус:** сделано в Фазе X (2026-10-19): ≤ 360 px бренд мельче (0.95rem), зазоры уже, слоган не скрыт; e2e `narrow-320.spec.ts`. Вид можно поправить по желанию (перенос/скрытие слогана).
