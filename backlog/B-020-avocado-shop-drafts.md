# B-020 — Черновики для магазина Avocado Kiss (`is_published` у товаров/категорий/курации)

**Что (владелец, 2026-10-20).** В магазине Avocado нет состояния «черновик»: ни у одной из таблиц `products`, `shop_categories`, `product_categories`, `brands`, `shop_editors_picks`, `product_pairings`, `product_reading` нет колонки `is_published` — запись видна на сайте сразу после вставки (у CozyCorner и у рецептов/постов Avocado черновики есть).

**Почему важно.** Агент в claude.ai через скилл создаёт товары пачками («добавь 10 товаров»); любая ошибка публикуется на сайте мгновенно.

**Решение владельца.** Пока оставить как есть, вернуться позже — сейчас у владельца в работе новая функциональность, связанная с этим. До тех пор защита — **предупреждение и обязательное «да» в скилле** (Фаза P (часть 1), шаг P3).

**Предложение (когда понадобится).** Колонка `is_published boolean not null default false` у `products` (и при необходимости у категорий/курации), фильтр в лоадерах сайта, переключатель в админке (Products), миграция + пересборка кэша; уровень 3 (`database-migrations`, `database-reviewer`). Заодно — как быть с уже опубликованными товарами (бэкфилл `true`).

**Нужно решение владельца:** когда брать (после новой функциональности, которую он упомянул). **Статус:** ждёт решения (отложено).
