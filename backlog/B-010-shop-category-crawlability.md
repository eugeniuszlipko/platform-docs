# B-010 — Товары 13+ в категории Urban Gardener не видны краулеру

**Что.** Страница категории `/shop/[category]` рендерит на сервере только первые `PAGE_SIZE = 12` товаров; остальные догружаются кнопкой «Show more plants»/IntersectionObserver (`components/shop/ProductGrid.tsx`). У Googlebot нет клика по кнопке, ссылок пагинации нет, хаб `/shop` ведёт только на категории. Товар за 12-м местом находят лишь через sitemap или блок «Related» (слабый сигнал). Найдено SEO-ревью Фазы X (HIGH для роста каталога; сейчас в базе 10 товаров, в категории до 6 — проблемы нет).

**Предложение.** Пока каталог мал — отдавать на сервер все товары категории (или ≥ 48) как `initialProducts`, бесконечную прокрутку оставить для больших категорий; при росте — настоящие страницы `/shop/[category]/page/[n]` со ссылками `<a>` и собственным canonical.

**Нужно решение владельца.** Нет сейчас; вернуться, когда в какой-либо категории станет > 12 товаров (или перед массовым добавлением каталога).

**Статус:** новая.
