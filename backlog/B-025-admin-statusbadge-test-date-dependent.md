# B-025 — web.admin: тест StatusBadge зависит от даты и падает

**Что (2026-11-04, найдено в Фазе L).** `src/features/shared/StatusBadge.test.tsx`, тест «Scheduled — «Scheduled · Oct 25, 14:00» в локальном времени браузера» падает. Падает и на чистой ветке без изменений Фазы L (проверено через `git stash`).

**Где проявляется.** `npm test` в web.admin: 1 красный тест из ~1080. Вероятная причина — зашитая дата «Oct 25» стала прошлой, и бейдж больше не «Scheduled» (причина не выяснялась).

**Предложение.** Зафиксировать «сегодня» в тесте (`vi.setSystemTime`) или брать дату в будущем относительно текущей.

**Нужно решение владельца:** нет. **Статус:** новая.

**Статус (2026-11-19):** сделано. Тест теперь фиксирует «сегодня» через `vi.useFakeTimers()` + `vi.setSystemTime(new Date(2026, 9, 1, 12, 0))`; причина подтверждена: зашитая дата «Oct 25» стала прошлой, и бейдж показывал «Overdue».
