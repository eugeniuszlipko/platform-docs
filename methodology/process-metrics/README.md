# Скрипты замеров процесса (токены, код, тесты, правки)

> Сняты 2026-10-18 при сравнении фаз Urban Gardener без Superpowers и с ним. Результаты и выводы — [../superpowers-evaluation-2026-10.md](../superpowers-evaluation-2026-10.md).
> Нужны, чтобы повторить замер после изменений процесса (новые правила 2026-10-18) и сравнить на тех же метриках.

Все скрипты читают то, что уже лежит на диске: журналы сессий Claude Code (`~/.claude/projects/<проект>/*.jsonl` и `<сессия>/subagents/`), git репозиториев, исходники. Ничего не меняют. Python 3, без зависимостей.

| Файл | Что считает | Что править перед запуском |
|---|---|---|
| `session-tokens.py` | По каждой сессии: ходы, вход / запись в кэш / чтение кэша / выход, то же по субагентам, навыки, типы субагентов, модели | Путь `base` (папка проекта в `~/.claude/projects`) |
| `owner-messages.py <префикс-id-сессии> [длина]` | Реплики владельца в сессии с временем, для разметки «правок после сдачи» | — |
| `skill-carry-cost.py` | Стоимость текстов загруженных скиллов (первичная запись + перечитывание до конца сессии) отдельно для SP и прочих | Словарь `sess` (id сессии → фаза), множество `SP` |
| `git-phase-stats.sh <репо> <метка> <первый-коммит> <последний-коммит>` | Строки кода / тестов / SQL, число добавленных тест-кейсов, fix-коммиты, число коммитов в диапазоне | Диапазоны коммитов фаз |
| `code-test-metrics.py` | По файлам фазы: размер, `any`, `as unknown as`, подавления линтера, плотность комментариев; тестов, проверок на тест, тестов на ошибки, моков | Словарь `ranges` (репо → фаза → коммиты) |

## Как повторить замер для новой фазы

1. Найдите id сессий этапов фазы (`ls -t ~/.claude/projects/<проект>/*.jsonl`) и первые реплики (`owner-messages.py <id>`), впишите в `sess` / `names`.
2. `session-tokens.py` → таблица токенов. Условные токены: `вход + 1,25·запись_кэша + 0,1·чтение_кэша + 5·выход`.
3. Диапазон коммитов фазы → `git-phase-stats.sh` и `code-test-metrics.py`.
4. Реплики владельца после сдачи разметьте вручную по трём корзинам: **дефект** / **промах по требованию** / **дизайн-правка или новое**.
5. Занесите строку в таблицу «Следующие замеры» документа оценки.

Ограничения: журналы сессий хранятся не бессрочно (на 2026-10-18 самые старые от 14 сентября); не пересчитывайте веса цены между замерами, иначе сравнение теряет смысл.
