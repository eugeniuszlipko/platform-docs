# Мета — общие правила для всех проектов

> «Мета» — всё, что общее и глобальное, не зависит от конкретного сайта и применяется во всех проектах воркспейса (и будущих). Правила конкретного проекта —
> в его документах (`sites/<проект>.md`, планах фаз); Мета — здесь.

| Скилл | Что задаёт |
|---|---|
| [`meta-planning`](meta-planning/SKILL.md) | Как мы планируем и общаемся: шаблон плана для владельца, формат вопросов (опросник), граница «решаю сам / спрашиваю», старт и приёмка фазы, итоговая «Фаза X» |

## Как устроено подключение

Источник — файлы здесь (в git). Подключение — симлинками, чтобы был один экземпляр:

```bash
ln -s /Users/mdr/Documents/Projects/workspace-one/platform-docs/skills/meta/meta-planning ~/.claude/skills/meta-planning          # на уровне пользователя: все проекты на этом компьютере
ln -s ../../platform-docs/skills/meta/meta-planning /Users/mdr/Documents/Projects/workspace-one/.claude/skills/meta-planning      # в воркспейсе
```

Агенты без поддержки скиллов (Cursor, Codex и т.п.) читают тот же файл по ссылке из корневого `AGENTS.md` («Планирование и общение с владельцем»).

## Добавление нового мета-скилла

1. Папка `skills/meta/<имя>/SKILL.md` (frontmatter `name`, `description` — когда применять).
2. Строка в таблице выше, симлинки (команды выше), ссылка в корневом `AGENTS.md`, запись в память агента.
3. Если правило меняет формат общения с владельцем — обновить и шаблоны в `meta-planning`, чтобы формат оставался единым.
