# Urban Gardener — Фаза 1: дизайн-система и каркас

> Статус: **принят владельцем 2026-10-15** (см. «Отчёт исполнения» внизу). План утверждён владельцем 2026-10-15.
> Контекст: [../../urban-gardener.md](../../urban-gardener.md) (§5 токены), [roadmap](2026-10-14-urban-gardener-roadmap.md) (Фаза 1).
> Рабочая директория: `urban.gardener/`. Референс: `mockups/Urban Gardener.html`.

**Цель.** Общая оболочка сайта (токены, шапка, футер, базовые UI-примитивы, анимации), визуально
совпадающая с референсом на 1440 / 900 / 390. Без данных, без БД, без страниц контента.
**Не входит:** карточки статей/товаров (строятся в своих срезах, Фазы 2–3), реальный поиск (Ф7),
рабочая подписка и попап (Ф6), cookie-баннер/GA (Ф8), любые обращения к Supabase.

## Принятые решения (владелец, 2026-10-15)

1. Навигация: страницы **Coming soon** на каждый маршрут, на который ведут шапка и футер (`/articles`, `/shop`, `/about`, `/contact`, `/privacy`, `/terms`) — 404 на сайте быть не должно.
2. Соцсети: иконки ведут на главные страницы сетей (как в референсе); список — в `lib/site.ts`, заменим на реальные аккаунты позже.
3. Fade при смене страницы — делаем (лёгкий, отключается `prefers-reduced-motion`).
4. Расширенная доступность шапки (skip-link, `aria-expanded`, возврат фокуса) — делаем.
5. Карточки статей/товаров в Фазе 1 не строим (Фазы 2–3).
6. Шрифт — системный SF-стек, как в референсе.

## Скиллы и ревью для этой фазы

Перед работой загрузить: `frontend-a11y`, `react-patterns`, `testing`, `react-testing` (каталог — `platform-docs/skills/ecc/README.md`).
Перед просьбой о приёмке запустить ревьюеров: `a11y-architect` (шапка, меню, поиск, skip-link), `react-reviewer` + `typescript-reviewer`
(все `.tsx`/`.ts`); результаты — в отчёт фазы.

## Предпосылки и подводные камни (проверено)

1. **`app/_design` не маршрутизируется** — префикс `_` в Next 16 = private folder
   (`node_modules/next/dist/docs/01-app/01-getting-started/02-project-structure.md`, «Private folders»).
   Страница-стенд будет по адресу **`/design`** (в roadmap 1.5 было `/_design` — исправляем).
2. **Временный URL — это Production-деплой**, поэтому стенд нельзя спрятать за `VERCEL_ENV !== 'production'`:
   владельцу нужно смотреть его онлайн. Делаем публичным, `noindex`, без ссылок с сайта; удаляем/закрываем в Фазе 9.
3. **Reveal не должен прятать контент без JS** и вызывать мигание: в референсе `.reveal{opacity:0}` по умолчанию —
   в SSR это скрыло бы весь контент до гидрации. Решение в шаге 5.
4. **Sticky-шапка** требует `overflow-x: clip` на `html, body` (уже в `globals.css`; `hidden` ломает sticky).
5. Ссылки шапки и футера ведут на страницы, которых ещё нет → решение 1: страницы-заглушки Coming soon (шаг 7).
6. Перед кодом на API Next 16 / React 19 (`usePathname`, `next/link`, `next/image`, `metadata`) — сверка с
   `node_modules/next/dist/docs/` (правило репо).

## Шаги

Каждый шаг заканчивается зелёными `npm run lint`, `npm test`, `npm run build`. Коммитов/пушей агент не делает без команды.

### 1. Токены и база (`app/globals.css`, `lib/site.ts`)
- Перенести в `:root` все токены референса (§5 спеки): цвета, `--sf`, плюс производные, которые в референсе зашиты
  литералами и повторяются: радиусы (`--radius-card 16px`, `--radius-pill 40px`, `--radius-lg 22px`), тени
  (`--shadow-card`, `--shadow-nav`, `--shadow-step` для «ступеньки» кнопки), ширины контейнеров (`--wrap 1240px`,
  `--narrow 760px`, `--gutter 32px → 20px`), высоты (`--header-h`), `--ease`. **Никаких hex в CSS-модулях.**
- Типографика: `h1–h4` (600, ls −.03em, lh 1.05), body (lh 1.6, ls −.011em, antialiased), `html{scroll-behavior:smooth}`.
- Зерно-оверлей (`body::before`, SVG feTurbulence, `opacity:.035`, `mix-blend-mode:multiply`, `pointer-events:none`).
- Утилиты `.wrap` / `.narrow` — как глобальные классы (используются во всех страницах), keyframes `fade`, `rise`.
- `prefers-reduced-motion`: отключить `scroll-behavior`, hover-подъёмы и reveal.
- `lib/site.ts`: константы `SITE_NAME`, `TAGLINE`, `NAV` (Home/Articles/Shop/About), `FOOTER_COLUMNS`, `SOCIAL_LINKS`.
  Фаза 5 перенесёт часть в БД (`pages`/настройки) — поэтому один модуль-источник, не размазанные строки.
- Тест: `lib/site.test.ts` — NAV без дублей href, все footer-ссылки из известного набора маршрутов.

### 2. Иконки и логотип (`components/icons/`)
- `BrandMark` (SVG-лист из референса, две дуги), `SearchIcon`, `CloseIcon`, `MenuIcon`, `ArrowRight`,
  соцсети `InstagramIcon`, `XIcon`, `PinterestIcon` (пути берём из референса; `currentColor`, `aria-hidden`).
- Тест: каждая иконка рендерится и `aria-hidden="true"`.

### 3. Примитивы UI (`components/ui/`, один компонент = файл + CSS Module)
- `Pill` (ссылка/кнопка, состояние `on`), `Tag` (eyebrow-метка), `Eyebrow`, `ButtonLink` (варианты `primary` — clay со
  «ступенькой», `ghost`, `find` — moss), `SectionHead` (заголовок + ссылка «All … →»), `Breadcrumb`,
  `Callout`, `TipBlock` (moss-блок с листом; слот `children` под форму — форму подключит Фаза 7),
  `PageHead` (eyebrow + h1 + p + слот фильтров).
- Все — серверные компоненты, кроме тех, где нужно состояние. Компоненты принимают данные пропсами, ничего не тянут сами.
- Тесты (RTL): рендер, варианты, `aria-current`/`aria-pressed` у Pill, внешняя ссылка получает `rel="noopener noreferrer"`.

### 4. Шапка (`components/Header*.tsx`)
- Раскладка: grid `1fr auto 1fr`, sticky, blur-фон `rgba(244,239,228,.82)`, бренд слева, pill-навигация по центру
  (активный пункт — `--moss`), справа соцсети + кнопка Search; ≤860: nav прячется, появляется кнопка меню.
- Один клиентский компонент владеет состоянием `menuOpen` / `searchOpen` (как в референсе — открытие одного закрывает другое).
  Активный пункт — по `usePathname()`. Закрытие меню/поиска: Escape, клик вне, смена маршрута.
- **Доработки доступности относительно референса:** `aria-expanded` + `aria-controls` на кнопках, `aria-current="page"`,
  фокус в поле при открытии поиска и возврат фокуса на кнопку при закрытии, видимый `:focus-visible`, skip-link «Skip to content».
- Поиск в Фазе 1 — **только оболочка**: панель открывается/закрывается, поле печатается, Enter и результаты не подключены
  (Фаза 6). Подпись-заглушка не показывается.
- Тесты: переключение меню, Escape закрывает, `aria-current` на активной ссылке (мок `usePathname`), поиск открывается с фокусом.

### 5. Reveal и анимации (`components/Reveal.tsx`, CSS)
- Принцип: **без JS контент виден**. `Reveal` — клиентский компонент с IntersectionObserver:
  - на сервере рендерится видимым (без класса скрытия);
  - после монтирования элементы **ниже первого экрана** переводятся в скрытое состояние и проявляются при входе в viewport
    (stagger `index*70мс`, максимум 700мс, как в референсе);
  - элементы в первом экране не скрываются (нет мигания); hero использует CSS-анимацию `rise` с `animation-delay`.
- `prefers-reduced-motion` — анимации отключены, контент сразу виден.
- Fade при смене страницы (`.page.active{animation:fade}` в референсе): через `app/template.tsx` с CSS-анимацией (решение 3); отключается при `prefers-reduced-motion`.
- `Skeleton` — мерцающий блок (токены, без хардкода); из него Фазы 2–3 соберут скелетоны маршрутов.
- Тесты: мок IntersectionObserver — элемент ниже экрана скрывается и проявляется; при `prefers-reduced-motion` не скрывается.

### 6. Футер (`components/Footer.tsx`)
- Сетка `2fr 1fr 1fr 1fr` (≤920 → 2 колонки, ≤640 → 1), бренд + описание, три колонки ссылок из `FOOTER_COLUMNS`,
  нижняя строка «© 2026 Urban Gardener» + юр-ссылки `/privacy`, `/terms`. Год — вычисляется, не хардкод.
- Тест: колонки и копирайт рендерятся из `lib/site.ts`.

### 7. Сборка в `app/layout.tsx`, страницы Coming soon, стенд `/design`
- `layout.tsx`: skip-link → `Header` → `<main id="content">` → `Footer`. Placeholder главной подогнать (убрать `min-height:100svh`).
- Страницы-заглушки `app/{articles,shop,about,contact,privacy,terms}/page.tsx`: общий компонент `ComingSoon` (`PageHead` + короткий текст + ссылка на Home), собственный `metadata.title`, `robots: noindex`. Это временные страницы — их заменят Фазы 2–6. Тест: каждая отдаёт 200 и содержит h1.
- `app/design/page.tsx` (`noindex`): все примитивы, все состояния (pill on/off, кнопки, tag, callout, tip-блок, breadcrumb,
  section-head, skeleton, reveal-демо, палитра токенов с hex-подписями, типографическая шкала).
- Не добавлять стенд в навигацию и (будущий) sitemap. Пометка в roadmap Фазы 9: удалить/закрыть `/design`.

### 8. Тесты и проверки
- Компонентные (см. шаги 1–6), e2e `e2e/shell.spec.ts`:
  - шапка видна и остаётся в viewport после скролла (sticky);
  - при 390px меню скрыто, открывается кнопкой, закрывается Escape;
  - навигация подсвечивает активный пункт; `/design` отдаёт 200 и `noindex`;
  - нет горизонтального скролла на 390px (`scrollWidth <= innerWidth`).
- Сверка с референсом: агент делает скриншоты референса и стенда Playwright'ом на 1440/900/390 и описывает расхождения
  (автоматического pixel-diff не делаем — шрифты/антиалиасинг дают шум).

## Ручная проверка владельцем (чек-лист)

Открыть `https://urban-gardener.vercel.app/design` и референс рядом:
1. 1440px: шапка (логотип, pill-nav, соцсети, Search), футер, цвета, шрифт, радиусы совпадают с референсом.
2. Скролл: шапка прилипает, blur-фон, нет горизонтальной полосы.
3. 900px и 390px: шапка перестраивается, кнопка меню; меню открывается/закрывается; футер в 2 и 1 колонку.
4. Hover: pill-nav, кнопки (подъём + «ступенька»), ссылки; клавиатура — Tab показывает фокус, skip-link работает.
5. Search: открывается/закрывается (Escape, клик вне); результатов пока нет — это нормально.
6. Reveal: блоки ниже экрана проявляются при прокрутке; с отключённым JS всё видно.
7. Клик по Articles / Shop / About и ссылкам футера открывает страницу «Coming soon» (не 404).

## Отчёт исполнения (2026-10-15)

**Проверки:** `npm run lint` и `npm run build` чисто; `npm test` — 118 passed (18 файлов); `npm run test:e2e` — 34 passed.
Ревью-гейт: `a11y-architect`, `react-reviewer`, `typescript-reviewer` — CRITICAL нет; HIGH (порядок фокуса мобильного меню, контраст clay-текста) исправлены.

**Отклонения от референса (осознанные):**
- Текст логотипа в шапке — «Urban Soul of Plants» (как в референсе, `TAGLINE`); в футере и копирайте — «Urban Gardener». Иконка X вместо птицы Twitter (сайт ссылается на x.com).
- Мобильное меню на всю ширину (в референсе сжималось до ~112px из-за `justify-self:center` на абсолютном элементе).
- Мелкий clay-текст (eyebrow, tag, заголовки колонок футера, крошки, ссылки секций) — новый токен `--clay-text #9c4423` (5.6:1) вместо `--clay` (3.9:1 < AA).
- Соцсети на мобильном (≤860) — группа «Social media» внизу бургер-меню (в референсе на мобильном скрыты).
- Панель поиска — оверлей, не в потоке, лёгкая тень `--shadow-panel` (в референсе результаты тоже абсолютные).
- Placeholder поиска без `opacity` (было 3.0:1), поле — `type="search"` внутри `<form role="search">`.
- `TipBlock` вписан в контейнер (в референсе — полноширинная полоса со скруглёнными углами по краям экрана); при необходимости страница может вывести его вне `.wrap`.
- Fade страницы — только opacity, 0.25с (в референсе ещё translateY): без transform обёртка не становится containing block для fixed-потомков.
- Footer: нижняя строка — © + юр-ссылки (в референсе «Made with love…»).

**Открытое решение владельца:** кнопка `primary` — cream на clay даёт 4.20:1 (AA требует 4.5 для 16px/600). Вариант: фон `#a84e28` (5.2:1) — заметно темнее кнопки референса. Оставлено как в референсе до решения.

**Принятые к сведению (MEDIUM/LOW, не исправлялись):** год в футере фиксируется на момент сборки (статический пререндер); `Pill` без rest-пропсов; hover и selected у Pill выглядят одинаково (как в референсе); `loading.tsx` Фаз 2–3 должны добавить `role="status"` + скрытый текст «Loading…» (Skeleton декоративен); глобальные моки `next/link`/`next/image` в `vitest.setup.ts` пробрасывают не-DOM пропсы; `vite-tsconfig-paths` в Vitest 4.1 можно заменить на `resolve.tsconfigPaths`; единый `cx()` вместо повторяющегося `filter(Boolean).join(' ')`.
