# Urban Gardener — Фаза X: накопительный список проверок

> Правило: при приёмке **каждой** фазы агент дописывает сюда, что надо перепроверить в конце проекта. В Фазе X по списку формируется отчёт
> «решение → как проверено → итог». Сюда попадают решения владельца, правила, найденные баги и «подводные камни», которые легко сломать позже.
> Формат строки: источник (решение/фаза) · что проверить · чем (тест/SQL/браузер/ревью).

## Решения проекта (журнал [urban-gardener.md](../../urban-gardener.md) §2)

## Правила и уроки, которые легко сломать позже

| Откуда | Что проверить | Чем |
|---|---|---|
| Фаза 2 | У динамических маршрутов (`[slug]`) нет `loading.tsx` — неизвестный адрес отдаёт настоящий 404 (не 200) | e2e на `/…/nope` |
| Фаза 2 | В страницах нет `searchParams` (иначе страница динамическая) | grep |
| Фаза 2 | Админка пишет статьи только RPC `save_article` (атомарно); update/delete «0 строк» — ошибка | тесты `ugArticles`, SQL под ролями |
| Фаза 2 | e2e не зависят от точного числа живых статей/товаров — проверяют сидовые по названиям | ревью тестов |
| Фаза 2 | Новые таблицы без публичного чтения (`media`, `admin_folders`) закрыты от anon | SQL под ролью anon |
| Фаза 2 | Картинки: ключ бакета или внешний URL; внешние Unsplash — `unoptimized`; все ссылки отвечают 200 | скрипт `curl -I` по БД |
| Фаза 2 | Заглушка «Test Article» (и подобные тестовые записи) удалена из БД | SQL |
| Фаза 3 (план) | Плейсхолдеры `affiliate_url` заменены реальными партнёрскими ссылками; нет `rel` без `sponsored` | SQL + e2e |
| Фаза 3 / B-003 | URL-ы CozyCorner не изменены (проиндексированы); у Urban товар — плоский `/product/<slug>` с canonical | e2e + curl |
| backlog | Просмотреть `platform-docs/backlog/`: B-001 (крошки Cozy), B-002 (валюта) — решены/осознанно отложены | чтение |
| Фаза 3 (план) | Текст About без «No affiliate-driven recommendations», добавлен affiliate-disclosure | ручная |
