# Воркспейс — Фаза P, часть 2: раздел «Skills» в админке со скачиванием скиллов
> Статус: ОТЛОЖЕНА владельцем 2026-10-20 (вернёмся позже; ничего не начато, код не менялся) (начинать после части 1)
> Техническая спека (для агента): [../specs/2026-10-20-phase-p2-skills-download-spec.md](../specs/2026-10-20-phase-p2-skills-download-spec.md)

## 1. Коротко
В админке у каждого сайта внизу меню появляется пункт «Skills»: список скиллов этого сайта и кнопка «Скачать», которая отдаёт всегда свежий архив из нашего репозитория, готовый к загрузке в claude.ai. Так вы не ищете файлы вручную и видите, какая версия актуальна. Не входит: обновление самих скиллов и SEO-посты (это [Фаза P (часть 1)](2026-10-20-phase-p1-skills-upgrade.md)), автоматическая загрузка в claude.ai (технически невозможна).

## 2. Что вы получите
1. **P7 — Пункт «Skills» в меню.** Внизу бокового меню каждого сайта. Вы увидите: пункт на CozyCorner, Avocado Kiss, Urban Gardener.
2. **P8 — Список скиллов сайта.** Карточка: название, описание, версия и дата, кнопка «Скачать», короткая инструкция «как загрузить в claude.ai». CozyCorner — 2 скилла (контент и SEO-посты), Avocado — 2, Urban — 2 (после Фазы P). Вы увидите: карточки на каждом сайте.
3. **P9 — Кнопка «Скачать».** Нажатие собирает архив из актуальных файлов репозитория и скачивает его. Вы увидите: файл `<имя-скилла>.zip`, который принимает claude.ai.
4. **P10 — Мобильная версия и тесты.** Раздел удобен на телефоне (390 px), покрыт тестами. Вы увидите: зелёные проверки и скриншот на 390 px.

## 4. Что я решил сам
- Для сборки архива нужна небольшая библиотека (zip); подключу только с вашего согласия при старте шага P9.
- Список скиллов и их файлов — в настройках админки (`sites.ts`), описание, версия и дата читаются из начала файла скилла.
- Если GitHub недоступен — кнопка показывает понятную ошибку, а не пустой архив.
- Страница одной линией с остальными разделами по виду (карточки, стили админки).

## 5. Риски и что не войдёт
- **Репозиторий `platform-docs` публичный:** тексты скиллов может прочитать любой, у кого есть ссылка (секретов в них нет). Если репозиторий станет приватным, вариант A перестанет работать — тогда переход на Release из GitHub Action.
- Загрузка в claude.ai остаётся ручной (кнопка «Загрузить скилл» в настройках claude.ai).
- Проверка доступа GitHub из браузера (CORS) — в начале P9; если не пройдёт, возвращаемся к вам с вариантом B.
- Не входит: версионирование/откат скиллов, автообновление.

## 6. Как вы проверите
1. Откройте любой сайт в админке → внизу меню «Skills» → видите карточки скиллов этого сайта.
2. Нажмите «Скачать» → скачивается `.zip`.
3. Загрузите его в claude.ai (Settings → Skills) → скилл принят без ошибок.
4. Измените слово в скилле в репозитории, подождите ~5 минут, скачайте снова → в архиве новая версия.
5. Откройте раздел на телефоне (390 px) → карточки не вылезают за экран, кнопка нажимается.
